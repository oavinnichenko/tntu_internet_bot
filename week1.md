# 📅 Week 1 — WordPress Developer Roadmap

Мета тижня: закріпити базу PHP, зрозуміти хуки й фільтри у WordPress, написати свій перший плагін, потренуватись із Git.

---

## ✅ Day 1. Організація + повтор PHP
- [ ] Створити GitHub-репозиторій `wp-learning-roadmap`
- [ ] Додати `README.md` з чеклістом
- [ ] Повторити основи PHP (змінні, цикли, масиви, функції)
- [ ] Написати функцію `greet_user($name)` → “Привіт, $name”
- [ ] Завантажити приклад у репозиторій (`/php-practice`)

---

## ✅ Day 2. OOP в PHP (база)
- [ ] Прочитати про класи, об’єкти, властивості, методи
- [ ] Створити клас `Car` з властивостями `brand`, `speed` і методом `drive()`
- [ ] Додати код у `/php-practice/oop-basics`

---

## ✅ Day 3. WordPress Hooks (перше знайомство)
- [ ] Розібрати різницю між **actions** і **filters**
- [ ] Використати `the_title` → додати “🚀” до кожного заголовка
- [ ] Використати `the_content` → додати “👉 Дякуємо за читання!” у кінець поста
- [ ] Зберегти код у `/wp-hooks-filters`

---

## ✅ Day 4. Шорткоди
- [ ] Прочитати про `add_shortcode()`
- [ ] Реалізувати `[current_year]`, який виводить поточний рік
- [ ] Використати його у пості
- [ ] Додати код у `/shortcodes/current-year`

---

## ✅ Day 5. Кастомний плагін
- [ ] Розібрати структуру плагіна (PHP-файл із коментарями + функції)
- [ ] Створити плагін `simple-badge-plugin`
- [ ] Логіка: додати бейдж “🔥 Популярне” перед заголовком, якщо пост у категорії *Featured*
- [ ] Завантажити у `/plugins/simple-badge-plugin`

---

## ✅ Day 6. Git практика
- [ ] Створити гілки (`week1`, `main`)
- [ ] Попрактикуватися з `commit`, `push`, `merge`
- [ ] Зробити комміт із повідомленням `"Added shortcode [current_year]"`

---

## ✅ Day 7. Підсумок
- [ ] Переглянути весь зроблений код
- [ ] Оновити `README.md` → відмітити виконане
- [ ] Написати нотатку: що було легко, що складно
